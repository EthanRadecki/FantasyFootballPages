Sign in

Saving writes the week’s file to the league’s GitHub repository, so the editor needs a GitHub token that can write to it. The token stays in this browser only.

How to make a token (once per device, about 2 minutes)
  1. On GitHub: your picture, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name it (for example “Rankings editor”), pick an expiration, and under Repository access choose Only select repositories and this site’s repository.
  3. Under Permissions, Repository permissions: Contents Read and write, and Actions Read and write (for the Start week button).
  4. Generate token, copy it, paste it here. GitHub shows it only once; you can delete it there any time to lock the editor again.

How writing works
  • Type plain text. Names, teams, positions and numbers are highlighted for you, as in the preview.
  • The first sentence is the key sentence (bold) and the synopsis. To pick another, wrap it in **two asterisks**.
  • [[img:id]] places a screenshot the week already has.
  • Ranks: type a number or use the arrows. Save draft as often as you like; the week is not on the site until you publish it.
